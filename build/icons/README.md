# Icons Directory

This directory contains the application icons in various sizes.

## Source Icon

- **AYM.png** (512x512) - The source icon file (tracked in git)

## Generated Icons

The following icons are auto-generated by running `../generate-icons.sh`:

- 16x16.png
- 32x32.png
- 48x48.png
- 64x64.png
- 128x128.png
- 256x256.png
- 512x512.png
- icon.png (copy of 512x512 for AppImage)

These generated files are ignored by git and will be created during the build process.

## Generating Icons

To regenerate all icon sizes from AYM.png:

```bash
cd build
./generate-icons.sh
```

Or manually with ImageMagick:

```bash
cd build/icons
convert AYM.png -resize 16x16 16x16.png
convert AYM.png -resize 32x32 32x32.png
# ... and so on
```

## Requirements

- ImageMagick (`sudo apt install imagemagick`)
