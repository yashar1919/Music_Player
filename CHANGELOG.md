# Changelog

All notable changes to AYMusic Player will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-07

### Added

- 🎵 Initial release of AYMusic Player
- ✨ Support for multiple audio formats (MP3, WAV, OGG, FLAC, M4A, AAC, WMA)
- 🎨 5 beautiful color palettes (Zorin, Ubuntu, Mint, Manjaro, Elementary)
- 🌓 Light/Dark/System theme support
- 📀 Album artwork display with automatic extraction
- 🎛️ Full playback controls (play, pause, stop, next, previous)
- 🔊 Volume control and mute functionality
- 📝 Playlist management with drag-and-drop
- 🎭 Real-time audio visualization
- 📱 Responsive design for all screen sizes
- 🐧 Linux file association support (.deb and AppImage packages)
- 🖥️ Desktop integration with .desktop file
- ⚡ Auto-play functionality when files are opened
- 🔄 Single instance support (all files open in same window)
- 💾 Persistent theme and palette preferences
- 🎨 Custom icon set in multiple sizes
- 📦 Professional packaging for Linux distributions

### Features

- **Smart Playback**: Automatic track progression and auto-play
- **Beautiful UI**: Modern gradient effects and smooth animations
- **Album Artwork**: Automatic metadata extraction and cover art display
- **Playlist Management**: Easy track addition, removal, and navigation
- **Theme Customization**: Multiple color palettes and theme options
- **Desktop Integration**: File associations and system tray support

### Technical

- Built with Electron 39.2.7
- React 19.2.3 for UI
- Vite 7.3.0 for fast development
- electron-builder for packaging
- Support for .deb and AppImage formats
